# Cours de technologie — La maison bioclimatique (5e)

Documents du cours « La maison bioclimatique » (technologie, classe de 5e).

## Contenu

- `cours_maison_bioclimatique.docx` — le cours (définition, orientation, compacité,
  énergie grise, isolation, hiver/été, ventilation, quiz, synthèse)
- `la_maison_bioclimatique_presentation.refaite.docx` — la fiche d'origine remise en forme
- `images/` — schémas extraits du PDF d'origine
- `cours_maison_bioclimatique_generer.py`, `generer_rapport.py` — scripts qui régénèrent les documents

## Régénérer les documents

```bash
pip install python-docx
python3 cours_maison_bioclimatique_generer.py
python3 generer_rapport.py
```
